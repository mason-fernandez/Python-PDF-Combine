# Python PDF Combiner

I'm so sick of using random websites to combine PDFs so here's a small python GUI to do it

## Features

- Select PDFs with windows file dialogue
- Combine them
- Save them with windos file dialogue

## Getting Started

### Prerequisites

- Windows 11
- Python 3
- PyPDF

### Build and Flash

```bash
git clone https://github.com/your-username/project-name.git
cd "Python PDF Combine"
python3 combine_pdf.py
```

## Usage

Run the program and select your files. Then choose your destination and save!

# Results and Lessons Learned

This is a small little program that runs and works in its most basic form. I was able to quickly combine the pdf I needed to. There is a lot of opportunity for more features so next time I have to combine a PDF I will look at expanding its functionality!

## Bugs

- The order that files are selected doesn't match the output order
- Closing file selection window doesn't close the program
